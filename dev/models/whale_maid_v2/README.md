## 造型与规格

548 个立方体、39 个骨骼、1024×1024 RGBA PNG 图集。所有可见表面使用逐面 UV；不是把参考图贴在平板上的模型。

手臂修订：肩袖、上下臂衣袖、金边及蕾丝袖口横截面宽/厚增加 10%，手掌和拇指增加 6% 保持衔接；长度、关节位置和原有动作不变。原眼睛贴图保留，在图集空白区增加眼睑贴图，不重画眼睛。

本次重新安排了头身比例、躯干和袖子的长度、外扩裙摆、腿部露出范围与头发长度。头部主体约占全高三分之一；头发分层形成较圆的体素外轮廓，长发延伸到裙摆，刘海密集遮挡额头。眼睛保持偏暗蓝、小幅收敛的处理。蕾丝头饰、耳侧蓝色蝴蝶结、鲸鱼围裙、金色裙纹、白色裙边与分叉鲸尾均单独制作。

含呆毛约 32 模型单位高。这里的建模单位不是最终 NPC 碰撞箱：若接入后希望约 1.5 格高，可在渲染器整体采用约 0.75 的缩放，再独立设置实体尺寸。本次没有添加该渲染器或修改实体尺寸。

## 骨骼与动画

主干为 `root → hips → spine → chest → neck → head`；双臂、双腿各有上段、下段和手/脚。后发、左右侧发各分三段；另有裙摆、左右裙片、围裙、呆毛、左右侧鳍及三段鲸尾。

- `animation.whale_maid_v2.idle`：4 秒循环，241 个关键帧；保留原 225 个身体动作关键帧，增加 16 个眼睑关键帧，于 2.70～3.00 秒眨眼一次。脚部固定。
- `animation.whale_maid_v2.walk`：4.8 秒原地循环，1397 个关键帧；原 1.2 秒步态连续重复四轮，步速不变，于 3.30～3.60 秒眨眼一次。原步态的所有身体关键帧数值保留并重复，包括根节点高度补偿。左右腿交替、反向摆臂、肘膝弯曲及附属部件跟随不变；实体水平位移仍需由后续代码控制。
- `animation.whale_maid_v2.blink`：0.3 秒单次动画，12 个关键帧；仅控制 `head` 下的 `eyelid_left` / `eyelid_right`。快速闭合、短暂停留再睁开，起止均为完全睁眼。
- `animation.whale_maid_v2.sleep`：4 秒循环，252 个关键帧；站立坐标系下持续闭眼，保留双臂、腿、尾巴、轻微呼吸和头部局部睡眠动作。整体躺卧交由游戏渲染器处理，动画不再旋转或平移 root。原 idle / walk / blink 不变，没有制作躺下或起床的过渡动画。
- 时间刻度 120；身体摆动使用 `catmullrom`，短促眼睑动作使用分段 `linear` 插值以避免过冲；每个已动画化通道的起止值一致。
- idle 和 walk 均已包含眨眼，播放任一动画都无需额外的眨眼控制器；不要再同时叠加独立 blink，避免眼睑通道冲突。独立 blink 保留供其他动作或手动预览使用。

### sleep 的定位约定

- sleep 的全部 `root.rotation` 和 `root.position` 关键帧均为 `[0, 0, 0]`。Blockbench 中保持站立坐标系；游戏渲染器负责床朝向、整体躺卧和床位定位，不在动画中重复应用。
- 两侧眼睑全程固定为 `position = [0, -3.65, -0.3]`；睡眠状态不要并行叠加 idle / walk / blink，避免根骨骼和眼睑通道互相影响。
- 旧卧床预览保存在 `before_sleep_root_identity` 备份中；新版预览不模拟游戏渲染器，不能作为真实床位对齐的测试结果。
- 2026-09-24 检查发现 `DswhaleRenderer.applyRotations` 仍有旧动画的特殊补偿：跳过默认躺卧旋转，并使用 `SLEEP_HEAD_ANCHOR_OFFSET` 补偿旧 root 位移。用户已明确要求 Java 渲染器另行处理，本次不改此分支；使用归零后的动画时需要配套调整。

## 自行补全的部分

1. 新参考没有绝对身高，先以约 32 单位建立比例；最终实体缩放留给游戏接入。
2. 不同视图中鲸尾的画面朝向不完全一致，统一为从后腰向角色自身左侧伸出，前后视图遵守同一个三维结构。
3. 被长发遮住的后背补为深蓝衣身；发束采用可动画的多段体素结构，不逐像素复刻参考里的高光与曲线。
4. 蕾丝、金纹和尾鳍纹理以分层几何和像素图案概括；围裙绘制独立鲸鱼标记。
5. 参考未提供动作，采用安静待机和小步行走；本次按用户补充要求添加自然眨眼，未添加攻击等其他动作。
